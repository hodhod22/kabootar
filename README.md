# Kabootar

Fullstack-programmeringsspråk — tidigare kallat Nova.

**Slutmål:** hela produkten är `.kab` — kompilator, VM, JIT, GC, CLI, stdlib, OS, browser. Rust i `src/` är **skuld** som ska **ersättas och raderas** ([SH28](docs/ROADMAP.md#kabootar-på-egna-fötter--noll-rust)). Ny `.rs`-feature är regression. En användare ska bygga och köra Kabootar **utan rustc**.

**[📖 Dokumentation](docs/README.md)** · **[Roadmap — noll Rust](docs/ROADMAP.md#kabootar-på-egna-fötter--noll-rust)**

```bash
kabootar              # REPL (produkt-CLI när den finns; idag bootstrap)
cargo run             # samma REPL via rustc — bootstrap/skuld, inte tak
cargo test            # host-tester — skuld tills SH25/SH28 (`kabootar test`)
```

Produktkompilatorn är `self_host/compile.kab`. Körning är Kab-VM (**kab-only default**). `.kab` kan även sänkas till **riktig x86-64-maskinkod** (AOT `lib/kab/aot/`): `aot_fn_lower` tar riktig compileIr-bytecode → `aot_fn_x64` emitterar hela fns (i64-domän + **`aot-tv1` taggad Value-repr**: SMI `v<<1` / heap-ptr `addr|1`, Kab-heap på data-sidan — `hbase`/`halloc` bump-allokering, `hload`/`hstore` fält, `hloadx`/`hstorex` array-index, `hloadb`/`hstoreb` sträng-bytes, `hlen`/`htag` header-dispatch, `jsmi`/`jnsmi` typdispatch — native/spegel-paritet bevisad i `sh28_aot_dyn_smoke`), **Float-celler** (`fmk`/`fadd`–`fdiv` SSE + `feq`/`fne`/`flt`/`fle`/`fgt`/`fge` `ucomisd` — `sh28_aot_float_smoke`), **numerisk widening** (SMI→Float-promotion via `fcast` i alla mixade aritmetik-/jämförelsepar, truncating `fmod`, `tconst64` för heltalskonstanter utanför i31-fönstret, float-konstanter via `aotF64Halves` — `sh28_aot_num_smoke` + `sh28_aot_num_src_smoke` på 9 riktiga `compileIr`-källor), **record/objekt-celler** (tag-10 shell → tag-11 slots, innehållshashade kid-nycklar i tag-4 str-celler — `make_object`/`get_member`/`member_set` (hit+grow)/`merge_object`/`object_rest`/`o["k"]` dynamisk medlemsåtkomst sänkta till heap-primitiverna; shell-indirektion bevarar alias-semantik; ärlig `isfalsy`-dispatch för `if`/`while` mot taggade konstanter — `sh28_aot_rec_src_smoke` på 13 riktiga `compileIr`-källor), **sträng-värden** (tag-4 celler — `add` konkatenerar str±str/str±SMI via `itoa`, `eq`/`ne` jämför innehåll, `.length` ur headern, `s[i]` → 1-char-cell/`tundef`, kid är innehållshash <2²⁰ så runtime-byggda nycklar `o["a"+"b"]` matchar statiska literal-kid — `sh28_aot_str_src_smoke` på 11 riktiga `compileIr`-källor), **Option/Result-celler** (tag-12 sum `[hdr|v]`, variant 0=none/1=some/2=ok/3=err — `make_*`/`jump_unless_*`/`unwrap_*`/`result_question`/`match_fail` sänkta till heap-primitiver; `dup`/`swap` som riktiga emitterade ops för match-maskineriet — `sh28_aot_opt_src_smoke` på 10 riktiga `compileIr`-källor), **match-machineriet** (`jump_unless_{object,object_empty,has_member,array,const_eq,enum_variant}` + `unpack_enum_fields`/`match_fail` + `index_peek_from_end`/`get_length` — enum-deklarationer installerar `{vmEnumNs,typeName,variants}`-records i modul-init, `E.V` resolveras via miss-fallback i `get_member`, ctor-anrop bygger `{vmEnum,typeName,variant,fields}`-records — `sh28_aot_match_src_smoke` på 24 riktiga `compileIr`-källor inkl. `?.`/`??` via inline-sänkta `__opt_*`-helpers), **array/slot-ops** (`take_*`/`array_push_*`/`array_pop_*` — push/pop kopierar till ny tag-5 cell, alias-säkert; `len_*`/`get_length`, `concat_array` för spread, `array_slice_*` vid destrukturering, `call_from_array` för `f(...xs)` med 0–3 arg via callv-register — `sh28_aot_arr_src_smoke` på 14 riktiga `compileIr`-källor), **throw/try/catch/finally** (`tryRegions` sänks statiskt: in-region `throw` → `jmp catchStart`; okontrollerad `throw` → tagg-13-markörcell via `ret`; varje call-site får markör-check som fångar eller propagerar uppåt — `sh28_aot_try_src_smoke` 11 källor inkl. kors-fram-propagering och okontrollerad markör-paritet), **builtin-trampoline** (`load_global <builtin>; call n` sänks inline via `aotBuiltinSeq` — `len`/`push`/`pop`/`slice`/`concat`/`typeof`/`str_slice`/`char_at`/`char_code_at`/`str_at`/`from_char_code`/`parse_int` (radix+prefix+NaN)/`abs`/`min`/`max`/`floor`-familjen/`is_*`-familjen/`object_has_own`/`object_array_push|pop`; övriga namn faller till gload+callv → ärlig trap — `sh28_aot_builtin_src_smoke` 58 källor), **bounds-checkad heap-tillväxt** (`hlimit` + data-mappning upp till 16 MiB — `sh28_aot_heap_smoke` skriver/ läser förbi en sida), **closure-celler** (`make_arrow_fn`→`mkclo` tag6 `[hdr|fnidx|cap…]` + dynamisk `callv`-dispatch — `sh28_aot_closure_smoke`), **sänkning från riktig `.kab`-källa** (`aotFnLowerModuleTv1`: `make_array`→heap-celler, `aget`/`aset`, `.length`→`hlen`, pilar→`mkclo`, runtime-typdispatch SMI/Float/`trap` — `sh28_aot_tv1_src_smoke`; resterande dynamiska Value rejectas ärligt — [docs/AOT-VALUES.md](docs/AOT-VALUES.md)) samt **GC** (`lib/kab/aot/aot_gc.kab` — mark/walk-audit + en collectorer syntetiserad i op-språket som körs identiskt i spegeln och som emitterad maskinkod: rot-protokoll via spill-region `[globals|spill|heap]`, `gcollect` mid-program + `hcalloc` collect-on-overflow med `ud2` bara vid fortfarande-full heap — `sh28_aot_gc_smoke`) → `os_native_exec` exekverar i-process, image i barnprocess via `kabootar exec-image`, och `aot_exe` paketerar imagen som **riktig PE32+/ELF64-exe** som startas direkt av OS:et (exit code = rax). Kedjan `.kab` → compile → x64 → exe är bevisad end-to-end (`examples/sh28/`). **SH33 multi-modul-AOT**: `aot_link` mergar hela import-grafer till en image — den riktiga 10-moduls self_host-DAG:n (`vm_ops_arith_a` + beroenden) länkas → 210 fns / 274 globals / 339 870 ops → **3 396 431 bytes x64 exekverade nativt** via återupptagbar checkpoint-emission (`examples/sh33/_sh33_s*`). Plan och **Nästa:** [docs/ROADMAP.md](docs/ROADMAP.md). Vision: [docs/OVERVIEW.md](docs/OVERVIEW.md).

CI producerar en nedladdningsbar release-binär (`.github/workflows/kabootar-artifact.yml` → artefakt `kabootar-linux-x64`) — idag fortfarande rustc-byggd; rustc-fri distribution kräver `nollAotReady`.
